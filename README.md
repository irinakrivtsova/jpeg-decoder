# JPEG Decoder

Проект реализует полный цикл распаковки базового (Baseline) стандарта JPEG "с нуля", без использования сторонних графических библиотек.

## Основные возможности

* **Baseline JPEG:** Полная поддержка базового алгоритма декодирования.
* **Чтение и парсинг маркеров:** Корректное чтение битового потока, таблиц квантования (DQT), таблиц Хаффмана (DHT) и комментариев (COM).
* **Алгоритмы сжатия:** Собственная реализация декодирования по алгоритму Хаффмана и обратного дискретного косинусного преобразования (IDCT).
* **Цветовые пространства:** Преобразование из YCbCr в RGB, а также поддержка изображений в оттенках серого (Grayscale).
* **Обработка ошибок:** Устойчивость к битым или некорректным JPEG-файлам с безопасным завершением работы (обработка "bad" изображений).

## Структура проекта

* `decoder/` — Исходный код ядра декодера:
  * `binaryreader.cpp` / `bitreader.cpp` — Низкоуровневое чтение битового потока.
  * `dct.cpp` — Обратное дискретное косинусное преобразование (IDCT).
  * `huffman.cpp` / `huffman-dec.cpp` — Декодирование по Хаффману.
  * `color_conversion.cpp` — Преобразование цветовых пространств.
  * `decoder.cpp` — Основная логика, управляющая процессом декодирования.
* `tests/` — Инфраструктура для тестирования:
  * `test_baseline.cpp` — Тесты для проверки корректности декодирования базового JPEG.
  * `test_commons.cpp` — Общие вспомогательные тесты.
  * `images/` — Набор тестовых изображений (baseline, grayscale, corrupt/bad), а также эталонные PNG-файлы для верификации результатов.
* `CMakeLists.txt` — Скрипт сборки проекта.

## Сборка проекта

Проект использует систему сборки CMake. Для сборки библиотеки и тестов выполните следующие шаги:

### Требования

* Компилятор C++ (с поддержкой C++11 или выше)
* CMake (версии 3.x и выше)

### Инструкция по сборке

1. Клонируйте репозиторий:
   ```bash
   git clone <url_вашего_репозитория>
   cd jpeg-decoder
   ```

2. Создайте директорию для сборки и перейдите в нее:
   ```bash
   mkdir build
   cd build
   ```

3. Запустите CMake и соберите проект:
   ```bash
   cmake ..
   make
   ```

## Запуск тестов

Проект включает в себя набор тестов, которые проверяют различные этапы декодирования, а также устойчивость декодера к поврежденным файлам из папки `tests/images/bad/`.

После успешной сборки тесты можно запустить через CTest:

```bash
cd build
ctest --output-on-failure
```
